# Моди для Claude Code

Колекція модів для [Claude Code](https://claude.com/claude-code) з повністю українським інтерфейсом. Працюють і в терміналі, і в застосунку Claude. Нічого не надсилають в інтернет.

| Мод | Що робить | Версія |
|---|---|---|
| [**gauge**](#gauge--шкала) | Шкала контексту, лімітів і кешу підказок в одному рядку під полем вводу | 0.2.1 |
| [**relay**](#relay--естафета) | Передача роботи в чисте вікно, коли контекст заповнюється | 0.1.1 |

## Встановлення

```
/plugin marketplace add Sofilkanych/claude-code-mods
/plugin install gauge@sofilkanych
/plugin install relay@sofilkanych
```

Після встановлення відкрийте нову сесію. Оновлення всіх модів: `claude plugin marketplace update sofilkanych`. Налаштування мода: `/plugin configure <мод>@sofilkanych`.

## gauge — шкала

Один рядок під полем вводу (або над ним — налаштування `position`):

```
▰▰▰▰▱▱▱▱▱▱ 40% · ≈5 ходів до 90% · 5 год 42% (до 16:40) · тиждень 18% (до 18.10) · кеш 60 хв
```

- **Контекст** кольором: зелений, з 70% — жовтий, з 90% — червоний (межі налаштовуються). Одне сповіщення при переході в червону зону.
- **Прогноз** — скільки ходів до червоної зони за середнім приростом останніх ходів.
- **Ліміти** 5 год і тижня з часом скидання (приглушено, як прогноз; з 90% — червоним); ліміт, що вже скинувся, зникає сам.
- **Кеш підказок** — скільки ще живе (тривалість налаштовується: 1 год або 5 хв); наприкінці жовтіє, вистиглий — так і каже.
- Вузьке вікно — коротший рядок; рядок ніколи не переноситься.
- **`/gauge`** — з чого складається контекст, ліміти, кеш і прогноз.

Налаштування: `warnAt` (жовтий з, %), `alertAt` (червоний з, %), `cacheTtl` (`1h` або `5m`), `position` (`below` — під полем вводу, `above` — над ним).

## relay — естафета

1. Коли контекст заповнено на **80%** (поріг налаштовується), над полем вводу з'являється пропозиція з кнопками **«Передати»** і **«Пізніше»**. Поки Claude працює, вона не заважає; «Пізніше» відкладає її на +5%.
2. «Передати» (або `/relay` будь-коли) — Claude пише **документ передачі** зі сталою структурою: **Мета** · **Зроблено** · **Рішення** (і чому) · **Пастки** · **Далі** · **Стан**. Мод сам додає факти з git: незакомічені файли й останні коміти.
3. Мод перевіряє, що документ **справді записано** й він не порожній, і лише тоді очищує сесію. Немає документа чи хід перервано — сесія лишається як є. Передачу можна скасувати кнопкою або `/relay скасувати`.
4. Чисте вікно спершу в 3–5 рядках каже, **що зрозуміло** з документа, — і продовжує роботу. Перед видаленням, заливкою чи push питає.

`/relay список` — документи передачі цього проєкту. Вони лежать у `~/.claude/relay/<тека проєкту>/`.

Налаштування: `threshold` (з якого заповнення пропонувати передачу, 50–95%).

## Статус

Моди ранні (0.x). Поведінку кожного покрито тестами й незалежним рев'ю коду; дещо (наприклад, очищення сесії з мода в `relay`) варто перевірити у своєму середовищі. Перевірити самому:

```
claude plugin validate plugins/<мод>
claude plugin test plugins/<мод>
```
