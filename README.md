# relay — естафета для Claude Code

Мод для [Claude Code](https://claude.com/claude-code): коли контекст заповнюється, однією кнопкою передає роботу в чисте вікно — без втрати того, що важливо.

## Як це працює

1. Коли контекст заповнено на **80%** (поріг налаштовується), над полем вводу з'являється пропозиція з кнопками **«Передати»** і **«Пізніше»**. Поки Claude працює, вона не заважає; «Пізніше» відкладає її на +5%.
2. «Передати» (або `/relay` будь-коли) — Claude пише **документ передачі** зі сталою структурою:
   **Мета** · **Зроблено** · **Рішення** (і чому) · **Пастки** · **Далі** · **Стан**.
   Мод сам додає факти з git: незакомічені файли й останні коміти.
3. Мод перевіряє, що документ **справді записано** й він не порожній, і лише тоді очищує сесію. Немає документа чи хід перервано — сесія лишається як є.
4. Чисте вікно спершу в 3–5 рядках каже, **що зрозуміло** з документа, — і продовжує роботу. Перед видаленням, заливкою чи push питає.

`/relay список` — документи передачі цього проєкту.

## Встановлення

```
/plugin marketplace add Sofilkanych/claude-code-relay
/plugin install relay@relay
```

Відкрийте нову сесію. Змінити поріг: `/plugin configure relay@relay` (від 50 до 95%).

## Де що зберігається

Документи — у `~/.claude/relay/<назва теки проєкту>/relay-РРРРММДД-ГГХХСС.md`. Мод нічого не надсилає в інтернет.
